# IoT Fingerprint Attendance System - Web Dashboard

This repository contains the Django-based web administration panel and REST API backend for the IoT Employee Attendance Logging System. It acts as the central hub, receiving telemetry and biometric authentication events from physical ESP32 scanner endpoints, managing employee profiles, and providing administrators with comprehensive attendance reports.

## 🚀 Key Features

* **Centralized Administration Dashboard:** A responsive, web-based interface for HR and administrators to monitor daily attendance logs, view employee statuses, and generate reports.
* **Robust Database Logging Logic:** Ensures secure, structured, and reliable capturing of incoming attendance payloads (timestamps, device IDs, template IDs) sent from the hardware endpoints across the network.
* **Automated User Profile Enrollment:** Streamlines the onboarding process by seamlessly linking physical fingerprint template IDs generated by the ESP32 with complete employee profiles in the database.
* **Hardware-Optimized REST API:** Exposes lightweight, efficient endpoints utilizing Django REST Framework (DRF) specifically designed to handle multi-device networking and synchronization.

## 🛠️ Tech Stack & Architecture

* **Backend Framework:** Python 3, Django
* **API Layer:** Django REST Framework (DRF)
* **Database:** SQLite (development) / PostgreSQL (production recommended)
* **Deployment (Optional):** Compatible with Docker ecosystem orchestration for scalable deployment, along with Daphne ASGI or Celery task workers for extended asynchronous logging.

## ⚙️ Setup and Installation

### 1. Clone the Repository
```bash
git clone [https://github.com/nima-mojarradi/finger_print-web.git](https://github.com/nima-mojarradi/finger_print-web.git)
cd finger_print-web

```

### 2. Environment Setup

Create and activate a virtual environment to manage dependencies securely:

```bash
python -m venv venv

# On Linux/macOS:
source venv/bin/activate
# On Windows:
venv\Scripts\activate

# Install required packages
pip install -r requirements.txt

```

### 3. Database Migration

Initialize the database schema for the user profiles and attendance logging logic:

```bash
python manage.py makemigrations
python manage.py migrate

```

### 4. Administrator Account

Create a superuser to access the Django admin panel and dashboard:

```bash
python manage.py createsuperuser

```

### 5. Launch the Server

Start the development server. To allow your ESP32 hardware to communicate with this backend over your local Wi-Fi network, run the server on `0.0.0.0`:

```bash
python manage.py runserver 0.0.0.0:8000

```

*(Note: Ensure your machine's firewall allows incoming connections on port 8000).*

## 📡 API Endpoints

The backend routes are structured to accept JSON payloads from the microcontroller units:

* `POST /api/attendance/` - Logs an employee clock-in or clock-out event.
* `POST /api/enroll/` - Registers a new fingerprint template ID to the central database during the automated enrollment phase.
* `GET /api/status/` - Device health check and network synchronization endpoint.

## 🤝 Hardware Integration

This web backend is explicitly designed to operate in tandem with the [finger_print_device](https://github.com/nima-mojarradi/finger_print_device) repository. Flash the C++ firmware to your ESP32 units and configure them to point to this server's local IP address to complete the system architecture.
